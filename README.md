# Astrovascular Response Dynamics — Computational Supplement

Reproducible computational feasibility analysis accompanying the critical mechanistic review **“Astrovascular Response Dynamics and Cognitive Reliability in Early Alzheimer's Disease.”**

## Scope

This repository implements a **reduced illustrative model**, not a data-driven fit to AD patients. The notebook reproduces simulated fast and delayed neurovascular response trajectories, a fixed-neural-drive-conditioned residual contrast (`M`), a complementary relative response-shape contrast (`S`), duration-dependent comparisons, and deliberately selected measurement-artifact sensitivity analyses. It does **not** demonstrate astrocyte-specific causality, tissue oxygen delivery, or a vascular cause of cognitive variability.

All parameters and 50% gains used to define the competing mechanisms are illustrative and predeclared in the notebook. The synthetic observation model is an additive, temporally correlated vascular-response proxy; it should not be treated as a validated EEG–fNIRS forward model.

Use **Python 3.12** (tested with Python 3.12-compatible NumPy / SciPy / Matplotlib; other modern versions may work).

```powershell
cd "$HOME\Downloads\Astrovascular_GitHub_Ready"
python -m pip install -r requirements.txt
jupyter notebook Astrovascular_Final_Simulation.ipynb
```

In Jupyter, choose **Kernel → Restart Kernel and Run All Cells** (or the corresponding JupyterLab menu). No network access, private data, or downloaded datasets are required after installation. Expect a short local run; exact runtime depends on hardware. Outputs write to the notebook's current working directory in `figures/` and `results/`.

## Reproducibility safeguards

1. Binary stimulation protocols include fixed baselines and recovery periods. The neural state update is checked against an independent high-precision integrator for all protocols.
2. The nonnegative FIR predictor is calibrated on separately generated trials; held-out protocol signals are not used for fitting.
3. `M` and `S` are computed with fixed early/late windows and no scenario-specific predictor retraining. `S` is defined only for sufficiently positive window means.
4. Gaussian AR(1) observation noise uses documented deterministic seeds. Reference limits for the S analysis are estimated from a calibration set **independent** of the test draws.
5. Amplitude-matched noise calibration illustrates how fixed absolute noise changes false-alarm frequency after a gain reduction. It presumes gain is known *in simulation*; it is **not** a deployable clinical calibration rule.
6. Simulation outcomes that are unfavorable to identifiability or that show sensitivity to latency, drift, or neural observation error are retained, not filtered.

## Equations and scientific interpretation

- **(6.1):** `e(t) = V(t) − Vhat(t | N, X)`; the demonstration conditions on the simulated neural signal and does not instantiate clinical/systemic covariates `X`.
- **(6.2):** `M = mean(e_late) − mean(e_early)`; a signed residual contrast, not a specific index of endfoot function.
- **(6.4):** `S = log[(mean(V_late)/mean(Vhat_late))/(mean(V_early)/mean(Vhat_early))]`; a relative response-shape summary, sensitive to latency and baseline drift.
- **(6.3):** the proposed hierarchical behavior model is **not** simulated or validated here, since no behavioral data were supplied.

All reported “flag rates” refer to simulated measurement distributions under the chosen perturbations, not medical diagnostic sensitivity/specificity. For questions about the biological interpretation, refer to the review manuscript and supplementary methods.
